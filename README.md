# Çatı ustası sitesi

Kişisel bir çatı ustası için beş farklı landing page tasarımı. Hepsi tek dosyalık statik HTML, sunucu gerektirmez.

- `site/index.html` — beş tasarımı listeleyen ana sayfa
- `site/1-usta/` … `site/5-mahalle/` — tasarımlar
- `site/README.md` — gerçek bilgilerle değiştirilecek yerler ve fotoğraf dosya adları

İsim, telefon, rakamlar ve yorumlar örnektir.
